# Security

Sentinel Edge is an offline-first research MVP and is not an official emergency-warning system.

Report suspected vulnerabilities privately to the project owner. Do not include credentials, private sensor data, or customer information in issues or fixtures. The public candidate uses deterministic fixtures, bounded parsers, authenticated API boundaries, incident authority journaling, and explicit evidence provenance.

The emulated-Arm64 profile does not claim Raspberry Pi secure boot, physical-device security, or production deployment security.
